#+TITLE: Phase 1 - Sub-state Machines (Hierarchical)
#+AUTHOR: Carl Olsen
#+DATE: 2026-06-04

* Feature Overview

Add support for hierarchical (nested) state machines. Users can define
multiple named machines in separate tabs. When a state name in one machine
matches another machine's name, it is treated as a sub-state-machine reference.

* Goals

- Allow defining multiple state machines in a single session
- Implicit sub-SM detection via name matching
- Generate correct Boost.SML C++ for composite states
- Generate nested PlantUML composite state diagrams

* Non-goals

- Explicit sub-SM declaration UI (kept implicit for simplicity)
- Cross-machine event forwarding or shared context (deferred to Phase 3)

* Constraints and Assumptions

- Elm 0.19.1 (no newer features)
- Sub-SM references use =sml::state<SubSM>= (no =class= keyword)
- Regular states use =sml::state<class StateName>=
- C++ structs emitted in dependency order (leaf-first, root-last)
- A machine cannot reference itself (no recursion)

* Risks and Open Questions

- Circular sub-SM references need detection and error reporting
- Tab ordering vs dependency ordering for code generation
- How to handle renaming a machine that is referenced as a sub-SM

* High-level Architecture

** Model Changes (Col/ModelData.elm)

#+begin_src elm
type alias Machine =
    { name : String
    , tableData : List TableDataRow
    }

type alias Model =
    { machines : List Machine
    , activeMachine : Int
    , mainContent : String
    }
#+end_src

- =systemName= removed; root machine is =machines[0].name=
- =getAllStates= filters out ="X"=, ="x"=, and =""=

** UI Changes (Main.elm)

- Tab bar showing machine names
- Active tab highlighted
- + button to add new machine tab
- x button to remove non-root machine tab
- Root tab name tied to =systemName=

** C++ Generation (Col/CppData.elm)

- =makeConstexprClass= skips sub-SM states (no constexpr alias emitted)
- Sub-SM references inlined as =sml::state<SubSM>= in transition rows
- =generateAllStructs= emits multiple structs in topological order (leaf-first)
- Circular references produce =// ERROR: circular sub-SM reference detected=

** PlantUML Generation (Col/PlantUml.elm)

- Detect sub-SM states and render as =state SubSM { ... }= blocks
- Recursively nest composite states (3+ levels supported)
- State names aliased with prefix inside nested blocks to avoid PlantUML collisions
- =makeNestedSystemString= handles multi-level nesting
- Auto-update on blur and tab switch
