#+TITLE: Phase 3 - Context Injection (Multi-Context)
#+AUTHOR: Carl Olsen
#+DATE: 2026-06-04

* Feature Overview

Add support for multiple context types that get injected into guard and action
lambdas. The user provides type names (e.g. =Ctx1=, =Ctx2=); the generated C++
code adds context reference parameters to lambdas and passes context instances
to =sml::sm<>=.

* Goals

- Allow specifying zero or more context type names for the generated state machine
- Generate guards/actions with all context parameters
- Generate =main()= that constructs and injects all contexts
- Keep it simple: user provides type names, writes the structs themselves

* Non-goals

- Generating the context struct definitions
- Per-machine context (contexts are global across all machines)
- Context member access helpers or code generation
- Per-lambda context selection (all lambdas get all contexts)

* Constraints and Assumptions

- Context types are global across all machines
- Variable naming: 1 context → =ctx=; 2+ contexts → =ctx0=, =ctx1=, ...
- Guard lambda signature: =[](const auto& event, Ctx1& ctx0, Ctx2& ctx1) { return true; }=
- Action lambda signature: =[](const auto& event, Ctx1& ctx0, Ctx2& ctx1) {}=
- =makeMain= passes all contexts: =Ctx1 ctx0{}; Ctx2 ctx1{}; sml::sm<SM> sm{ctx0, ctx1};=
- If no contexts specified, existing signatures remain unchanged
- =mainContent= is regenerated (not patched) when context types change

* Architecture

** Model (Col/ModelData.elm)

#+begin_src elm
type alias Model =
    { machines : List Machine
    , activeMachine : Int
    , mainContent : String
    , contextTypes : List String
    }
#+end_src

** CppData (Col/CppData.elm)

- =makeContextParams : List String -> String= — builds lambda param suffix
- =actionFmt= / =guardFmt= now take =ctxParams= string argument
- =interpolateAction= / =interpolateGuard= take =ctxParams= as first arg
- =makeEventHeader : List String -> List (List String) -> String= — first param is context types

** Default (Col/Default.elm)

- =makeMain : String -> List String -> String= — name + contextTypes
- Generates context variable declarations and passes them to =sml::sm<>=

** Main (Main.elm)

- New =Msg= variants: =AddContext=, =RemoveContext Int=, =UpdateContext Int String=
- =makeContextInput : Model -> Html Msg= — repeatable list UI with +/- buttons
- Context changes regenerate =mainContent= via =DF.makeMain=
- =generateFullCode= passes =model.contextTypes= to =Cpp.makeEventHeader=
- =renameMachine= passes =model.contextTypes= to =DF.makeMain=
