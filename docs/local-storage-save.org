#+TITLE: Feature: Local Storage Auto-Save
#+AUTHOR: Carl Olsen
#+DATE: 2026-06-05

* Feature Overview

Persist the entire model (machines, context types, main content) to browser
localStorage on every change. Restore automatically on page load so the user
never loses their work after a reload.

* Goals and Non-Goals

** Goals
- Auto-save on every model change (no manual "save" button needed)
- Restore full state on page reload (machines, tabs, context types, main content)
- Zero friction -- user doesn't need to do anything

** Non-Goals
- No export/import to JSON file (future feature)
- No server-side persistence
- No versioning or undo history
- No multi-tab sync (last write wins)

* Constraints and Assumptions

- Elm 0.19.1 has no direct localStorage access; must use ports
- localStorage limit is ~5-10MB per origin (more than enough for our model)
- Static deployment to nginx (no backend)
- Current init signature: ~init : () -> (Model, Cmd msg)~
- Current JS init: ~Elm.Main.init({ node: ... })~ with no flags

* Risks and Open Questions

| Risk/Question                     | Mitigation                                        |
|-----------------------------------+---------------------------------------------------|
| Schema changes break saved data   | Decoder falls back to default model on failure    |
| Large tables slow down save       | Unlikely; JSON encode is fast for this data size  |
| localStorage unavailable          | Graceful fallback to default model (private mode) |

* High-Level Architecture

** Save Flow
1. Every branch in ~update~ that modifies the model emits ~saveModel (encodeModel newModel)~
2. JS subscribes to ~port saveModel~ and writes to ~localStorage.setItem("elm-sml-model", json)~

** Load Flow
1. JS reads ~localStorage.getItem("elm-sml-model")~ before Elm init
2. Passes the raw JSON string (or null) as flags to ~Elm.Main.init({ flags: saved })~
3. Elm ~init~ accepts ~Json.Decode.Value~ flag, attempts decode
4. On decode success: use restored model
5. On decode failure (null, corrupt, schema mismatch): use default model

** Data to Persist
All fields of ~Model~:
- ~machines : List Machine~ (name + tableData with rowIndex, selected, RowData)
- ~activeMachine : Int~
- ~mainContent : String~
- ~contextTypes : List String~

** JSON Shape (example)
#+BEGIN_SRC json
{
  "machines": [
    {
      "name": "StateMachine",
      "tableData": [
        {
          "rowIndex": 0,
          "selected": "No Special",
          "data": {
            "startState": "A",
            "endState": "B",
            "event": "ev1",
            "guard": null,
            "action": "doStuff"
          }
        }
      ]
    }
  ],
  "activeMachine": 0,
  "mainContent": "int main() { ... }",
  "contextTypes": ["MyCtx"]
}
#+END_SRC
